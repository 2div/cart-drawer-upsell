# App Store Media Checklist

Use this before capturing screenshots, GIFs, or videos for the Shopify App
Store listing. Media should show the real app UI and real storefront behavior.

## Capture Rules

- Use a clean test store with realistic products and product images.
- Use the storefront preview in a normal browser tab for cart behavior.
- Use the theme editor only when showing app embed settings.
- Hide browser bookmarks, personal accounts, unrelated extensions, and desktop
  notifications.
- Do not show customer personal data, real orders, payment details, or private
  store data.
- Do not use unsupported claims in image text.
- Do not show features that are not currently available in the app.

## Required Screenshot Set

Capture these states before submission:

1. Storefront drawer with cart items, quantity controls, remove icon, subtotal,
   and checkout button.
2. Storefront drawer with recommendation products visible.
3. Empty cart drawer with recommendations and continue shopping button.
4. Theme editor app embed settings showing drawer copy, progress, colors,
   recommendation count, order note, and discount toggles.
5. Embedded admin app showing saved recommendations and setup status.
6. Mobile drawer view with cart items and recommendations.

## Optional Media

Optional but useful:

- Short GIF or video showing Add to Cart opening the app drawer.
- Short GIF or video showing a recommendation product being added.
- Short GIF or video showing free-shipping progress updating.

## Recommended Test Data

Prepare the test store with:

- At least three active products with clear product images.
- At least one product already in the cart.
- At least two saved recommendation products.
- One sold-out recommendation product to show disabled behavior.
- A free-shipping goal that makes the progress bar visibly useful.
- Order note and discount code sections enabled for one screenshot.

## Quality Checklist

Before using any media:

- Text is readable at App Store listing size.
- The drawer is not cut off.
- Buttons and product names are not overlapping.
- The cart subtotal and recommendations are visible.
- The app name and branding are not confused with Shopify or a theme name.
- The screenshot does not show dev-only console panels.
- The screenshot does not show test warnings that merchants would not see.
- Colors have enough contrast to read product text and actions.

## Captions Draft

Use short captions that describe what the screenshot shows:

- Cart drawer with editable quantities and checkout
- Product recommendations inside the drawer
- Empty cart with recommendations
- Theme editor app embed settings
- Admin setup for recommendation products
- Mobile cart drawer experience

Keep final captions aligned with the exact screenshots used.
