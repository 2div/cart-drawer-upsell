## Short Description

Cart Drawer Upsell helps merchants replace their theme cart drawer with a
configurable app drawer that supports manual upsell products, free-shipping
progress, cart notes, discount codes, and checkout.

The app installs through a Theme App Extension app embed, so merchants can
enable it from the theme editor without manually editing theme files.

## Feature Bullets

- Replace supported theme cart drawers with an independent app drawer.
- Choose up to four product variants to recommend inside the cart drawer.
- Show free-shipping progress with merchant-configurable messages.
- Let shoppers update quantities, remove products, add order notes, apply
  discount codes, and proceed to checkout.
- Disable sold-out upsells automatically and show shopper-friendly messages.
- Configure drawer heading, colors, upsell heading, upsell count, order note,
  discount code, and progress bar settings from the theme editor.

## Online Store Requirement

This app depends on the Online Store sales channel because the main feature is a
Theme App Extension app embed that renders on storefront theme pages.

In the listing form, indicate that merchants must have an Online Store.
